# 山竹漫剧 v0.1.4

## 本次更新

- 视频生成节点会优先读取模型广场在线详情中的明确时长范围或固定秒数。
- 支持 10 秒、15 秒、30 秒等不同模型能力；`video_特惠` 分组不再统一限制时长。
- 模型详情沿用现有 10 分钟目录同步，后续只调整线上详情即可同步到 Windows 与 Mac。
- 同时提供 Windows x64、macOS ARM64 与 macOS x64 安装包。

## 下载与安装

- Windows 用户下载 `MangosteenStudio-Windows-x64-v0.1.4-Setup.exe` 后覆盖安装。
- Apple Silicon Mac 下载名称含 `arm64` 的 DMG，Intel Mac 下载名称含 `x64` 的 DMG，然后将应用拖入“应用程序”文件夹。
- GitHub 与 Gitee Release 提供同一批附件；可使用 `SHA256SUMS` 核对下载文件。

## 安全提示

Windows 安装器暂未进行 Authenticode 代码签名，首次运行可能出现 SmartScreen 提示。Mac 安装包暂未进行 Developer ID 签名和 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

本版本不执行付费模型生成验证，账号中的实际可用模型、时长和费用仍以登录后显示的信息为准。
