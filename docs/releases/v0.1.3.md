# 山竹漫剧 v0.1.3

## 本次更新

- 新增 Windows 10/11 x64 安装包，沿用现有 Electrobun、NSIS 与 WebView2 桌面链路。
- 统一 `mangosteen-studio://` 安装协议及 `com.mangosteen.studio` 更新标识。
- Windows 安装包、完整更新包、更新清单及 `SHA256SUMS` 同步发布到 GitHub 与 Gitee。

## 下载与安装

本版本仅新增 Windows x64 版本。macOS 用户继续使用 [v0.1.2](https://github.com/CCCq-C/mangosteen-studio/releases/tag/v0.1.2)。

Windows 用户下载 `MangosteenStudio-Windows-x64-v0.1.3-Setup.exe` 后按提示安装。安装器会检查 WebView2；若系统缺失或版本过旧，请按安装界面完成微软组件安装或修复。

## 安全提示

Windows 安装器暂未进行 Authenticode 代码签名，首次运行可能出现 SmartScreen 提示。请只从本项目的 GitHub 或 Gitee Release 下载，并使用附件中的 `SHA256SUMS` 核对文件。

本版本不执行付费模型生成验证，账号中的实际可用模型与费用仍以登录后显示的信息为准。
