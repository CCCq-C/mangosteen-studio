# 山竹漫剧 v0.1.2

## 本次更新

- 按登录账号隔离并复用 AIHubKit 分组密钥，恢复已有密钥后再补建缺失分组，减少重复创建和切换账号等待时间。
- 新增官方社区，支持从 Gitee 优先、GitHub 备用的目录中安装 Skill，或向当前项目导入模板与工作流。

- 加入 GitHub/Gitee 双源更新检查基础设施；本版本因尚未配置 Apple Developer 签名与公证，仍采用手动下载安装。

## 安装

本版本支持 Windows x64 和 Apple Silicon（M1/M2/M3/M4）Mac。Windows 用户下载 `MangosteenStudio-Windows-x64-v0.1.2-Setup.exe` 后按提示安装；macOS 用户下载 DMG 后，将应用拖入“应用程序”文件夹。

Windows 安装包暂未进行代码签名，首次安装时可能出现 SmartScreen 提示，请选择“更多信息 → 仍要运行”；macOS 版本尚未完成 Apple Developer ID 签名与公证，如提示“无法验证开发者”，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。
