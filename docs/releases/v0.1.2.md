# 山竹漫剧 v0.1.2

## 本次更新

- 按登录账号隔离并复用 AIHubKit 分组密钥，恢复已有密钥后再补建缺失分组，减少重复创建和切换账号等待时间。
- 新增官方社区，支持从 Gitee 优先、GitHub 备用的目录中安装 Skill，或向当前项目导入模板与工作流。
- 隐藏内置媒体供应商预设，保留通用的自定义供应商入口。
- 将应用图标改为圆形透明山竹，并同步桌面端各尺寸图标。
- 加入 GitHub/Gitee 双源更新检查基础设施；本版本因尚未配置 Apple Developer 签名与公证，仍采用手动下载安装。

## 安装

本版本面向 Apple Silicon（M1/M2/M3/M4）Mac。下载 DMG 后，将应用拖入“应用程序”文件夹。

当前测试版尚未经过 Apple 公证。如果 macOS 首次阻止打开，请前往“系统设置 → 隐私与安全性”，选择“仍要打开”。

## 完整性校验

GitHub Release 与 Gitee Release 同时提供 `SHA256SUMS`。两个平台上的 DMG 文件应具有相同名称、大小和 SHA-256。
