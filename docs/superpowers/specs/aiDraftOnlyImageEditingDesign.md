# 新对话仅搭建与全图片模型图生图设计

## 目标

新对话负责把创作意图落实为画布节点、提示词、参考素材连线和推荐配置，但不替用户提交任何图片或视频生成任务。图片节点在用户手动点击发送后，允许所有当前账号动态同步到的图片模型尝试文生图或图生图。

## 交互边界

1. 新对话可以创建、移动、连接和选择节点，也可以读取节点配置并写入提示词与模型配置。
2. 用户明确指定模型时按指定的 `分组 + 模型` 填入；未指定时，AI 从节点实时返回的兼容图片或视频模型中推荐并预填，用户仍可在发送前修改。
3. 新对话不得调用图片或视频直接生成工具，也不得调用画布节点的 `node:generateImage`、`node:generateVideo`。限制必须在运行时工具边界执行，不能只依赖提示词。
4. 图片和视频任务只在用户点击对应节点的发送按钮后提交。音频生成不在本次改动范围。

## 图生图能力

1. AIHubKit 动态目录中的所有图片模型统一声明 `text`、`singleImage`、`multiReference` 三种能力。上游仍决定具体模型是否实际接受参考图；拒绝时原样显示可读错误，不静默降级成文生图，也不跨分组换模型。
2. 没有参考图时继续使用 `/v1/images/generations/tasks`，并保留当前同步接口回退。
3. 有参考图时使用 `/v1/images/edits/tasks`，以 `multipart/form-data` 重复提交 `image` 文件字段；异步接口不可用时回退 `/v1/images/edits`。
4. 参考图必须来自工作区。后端现有读取逻辑把本地文件转换为受限内存输入，供应商适配器再转为 `Blob` 加入 `FormData`，不暴露本地路径。
5. 图生图接口已经支持直接文件上传，因此本次不调用临时文件接口。临时文件只保留为未来某个模型明确要求公网 URL 时的独立适配路径；不保存上传令牌、预签名地址或临时 URL。

## 模型变化与失败处理

- 上游新增的图片模型自动继承图生图入口，无需客户端维护型号白名单。
- 上游删除模型时沿用现有行为：节点模型清空并提示重新选择。
- 某个模型拒绝参考图时，仅当前任务失败并显示上游原因；参考图、提示词和节点配置保留，用户可换模型后再次手动发送。
- 停止按钮继续通过现有 AbortSignal 取消等待和下载，不新增后台任务。

## 验收

1. 新对话能创建图片/视频节点、写入提示词、连接参考素材和预填模型，但无法启动图片或视频生成。
2. 用户手动点击无参考图图片节点时，仍走文生图接口。
3. 用户手动点击带一张或多张本地参考图的图片节点时，请求为 multipart 图生图，包含真实文件内容而不是本地路径。
4. 所有当前同步图片模型在节点模型目录中声明图生图能力；上游拒绝时不降级、不换模型。
5. 全仓类型检查、工具构建、节点构建、服务端构建和桌面打包通过；不提交付费生成任务作为自动验收。

## 已知限制

AIHubKit 模型目录目前不返回每个模型的参考图数量、蒙版和尺寸能力。本次按用户要求对全部图片模型开放入口，真实兼容性由上游响应决定。蒙版字段、模型级数量限制和临时 URL 型图片接口不在本次范围。
