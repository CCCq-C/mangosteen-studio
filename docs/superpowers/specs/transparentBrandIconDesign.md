# 圆形透明品牌图标设计

## 目标

保留现有山竹果实主体，把浅紫色正方形底板移除，输出四周透明、视觉主体为圆形的统一品牌图标，替换客户端、网页、移动端和安装包所引用的旧资源。

## 资产规则

- 主文件 `packages/assets/mangosteenAvatar.png` 为 1024×1024 RGBA PNG。
- 山竹主体居中，占画布约 82%，外圈保持透明，不增加方形底色、文字或描边。
- `logo.iconset` 从同一主文件生成，保持 macOS 所需的 16、32、128、256、512 与 1024 像素组合。
- Windows `logo.ico` 从透明 PNG 生成；移动端继续复用 512 像素 PNG。
- 删除未被使用且仍是旧图形的 `packages/assets/logo.svg`，避免后续误用。

## 验收标准

1. 主 PNG 与全部 iconset PNG 都包含 Alpha 通道。
2. 首页、登录页、对话助手和关于页继续使用同一山竹图标。
3. macOS 打包后的应用图标四角透明，主体在 Dock 中不被裁切。
4. Web 构建和 macOS 本地包构建通过。
