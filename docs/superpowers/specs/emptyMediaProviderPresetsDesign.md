# 清空媒体模型预设供应商设计

## 目标

开发者选项的“媒体模型”页不再展示随程序提供的预设供应商，只展示用户自行添加的供应商。

## 选定方案

在设置页的展示边界过滤内置媒体供应商：`tfRouter`、`apiMart`、`metaso`、`compshare`。底层适配器及用户本地已有文件继续保留，避免旧画布因升级直接丢失运行依赖。

“添加供应商”继续使用现有通用自定义接入表单，不增加预设模板或新的配置入口。

## 备选方案

1. 删除内置适配器文件：界面和运行时都会消失，但会直接破坏依赖旧供应商的画布。
2. 删除启动时安装逻辑：新安装不再出现预设，但已安装用户的旧文件仍会继续显示。
3. 仅在设置页过滤：满足当前界面清理要求，同时保留旧项目兼容性；本次采用。

## 数据与兼容性

- 不删除用户的供应商文件、API Key 或模型配置。
- 不改变 AIHubKit 动态模型目录及画布模型选择逻辑。
- 用户新添加的供应商正常显示、编辑和删除。
- 内置预设仍可供旧画布按原有路径调用，但不再作为可配置卡片展示。

## 验收

1. 打开“设置 → 开发者选项 → 媒体模型”，不显示四个内置供应商卡片。
2. 用户自行添加一个供应商后，该卡片正常显示。
3. 文本模型、模型渠道大全和 AIHubKit 画布模型列表不受影响。
