# 山竹漫剧 AIHubKit 分组模型设置设计

## 1. 目标

设置中的“文本模型”和“媒体模型”直接展示当前登录账户实时返回的 AIHubKit 分组与模型。动态图片模型不再只保存模型 ID，而是保存“分组 ID + 模型 ID”，生成时只使用用户明确选择的分组，避免后台静默切换倍率或渠道。

本批不接入文本生成和视频生成接口。文本与视频模型数量以实时目录为准，本批只在设置中展示；图片模型继续使用已经接通的生成链路，并增加精确分组选择。

## 2. 页面结构

### 文本模型

1. 首屏展示 AIHubKit 动态文本目录。
2. 每个分组显示上游说明、分组 ID、倍率和模型数量。
3. 展开分组后列出该分组包含的模型；同一模型在多个分组中分别出现。
4. 现有第三方与自定义供应商保留在“高级供应商”折叠区，不删除用户已有配置。

### 媒体模型

1. 首屏展示 AIHubKit 动态媒体目录。
2. 使用“图片 / 视频”两个页签；页签内部仍按分组展示。
3. 空分组不显示；本次同步部分失败时保留成功数据并显示提醒。
4. 现有第三方与自定义媒体供应商保留在“高级供应商”折叠区。

两个页面复用同一个目录组件和同一个前端请求缓存，不各自实现请求、分组或刷新逻辑。

## 3. 数据契约

Server 的公开目录增加顶层 `groups`，只包含：

- `id`：上游分组 ID；
- `label`：上游分组说明；
- `ratio`：上游返回的倍率字段。

`models` 继续包含模型 ID、类型和所属分组，不包含 Access Token、Cookie 或分组 API Key。新增桌面端 POST 接口 `/api/desktop/account/catalog`；`refresh: true` 时强制重新同步，否则复用十分钟缓存。

前端从顶层分组顺序构建页面；模型列表只依据当前响应，不硬编码 21 个分组或 97 个模型。分组或模型被上游删除后，下次同步即不再显示。

## 4. 分组选择与图片生成

通用媒体模型增加可选的 `groupId`、`groupLabel`、`groupRatio`。AIHubKit 图片目录为每个“分组 + 模型”关系返回一条可选项；其他供应商不受影响。

图片生成节点的新值使用三元组：

```text
[providerId, groupId, modelId]
```

旧的普通供应商仍使用原有二元组 `[providerId, modelId]`。已有 AIHubKit 二元组没有明确分组，加载新目录后清空选择并标记失效；用户重新选择后才能运行。

请求增加可选 `groupId`。当 `providerId` 为 `aiHubKit` 时，Server 要求 `groupId` 非空，并验证该分组当前仍包含所选图片模型；只注入该分组的私有 API Key，不再自动遍历其他分组。分组或模型失效时返回“这个节点的模型已失效，请重新选择模型”。

## 5. 状态与错误

- 首次打开设置：显示加载状态，成功后显示目录。
- 手动同步：按钮只允许一个在途请求；成功后同时清理节点模型缓存。
- 部分同步：显示“部分分组同步失败”，仍展示成功分组。
- 完全失败：保留已经加载的旧页面数据并显示可重试错误。
- 空分组：隐藏，不显示不可用卡片。
- 未识别模型：不进入文本、图片或视频列表，只显示未识别数量提示。

## 6. 边界

- 本批不实现 AIHubKit 文本请求、视频请求、数字人请求和余额功能。
- 本批不删除现有供应商文件、API Key 配置或高级编辑能力。
- 本批不把任何私有密钥返回 Web、写入画布或提交到 Git。
- 仓库禁止新增测试模块；验收使用已有类型检查、构建、真实目录接口与客户端页面检查。

## 7. 验收

1. 当前账号同步结果完整时，文本和媒体设置显示实时响应中的全部非空分组；不依赖开发时观察到的固定数量。
2. `森雪赚专用` 等零模型分组不显示。
3. 图片节点下拉按分组展示；同一图片模型在不同分组中是不同选项，并显示倍率。
4. 图片生成请求携带所选 `groupId`，Server 只解析该分组的密钥。
5. 删除所选分组或模型后，节点模型留空，运行时提示重新选择。
6. 现有第三方、自定义供应商配置仍可在高级区域查看和编辑。
