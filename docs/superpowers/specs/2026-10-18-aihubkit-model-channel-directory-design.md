# 山竹漫剧模型渠道大全与自动定价同步设计

- 状态：已确认，直接实施
- 确认日期：2026-10-18
- 上游定价入口：`https://model.aihubkit.com/api/pricing`

## 1. 目标与范围

在设置中增加独立、只读的“模型渠道大全”，登录后自动展示当前账号可用的渠道、模型、上游介绍、计费方式、分辨率价格和同步状态。页面不提供启停、编辑或 API Key 操作；正常状态下用户无需点击同步。

本批同时把定价详情同步从完整模型目录同步中解耦：软件每次恢复登录或登录成功后后台刷新一次，运行期间每十分钟刷新，失败时继续使用当前账号最近一次成功快照。

本批不建设公网服务器、不汇总不同用户、不修改上游数据、不通过介绍文字猜价格，也不扩展新的生成能力或模型参数。

## 2. 已验证的上游数据

2026-10-18 对 `GET /api/pricing` 完成只读核对。单个 JSON 已包含：

- `pricing_version`：整批定价版本；
- `usable_group`、`group_ratio`：渠道说明与当前请求对应的分组倍率；
- `vendors`：厂商 ID、名称和图标；
- `data`：模型名称、可用分组、介绍、标签、图标、厂商、端点类型和计费公式；
- `billing_expr`：按输出秒、按条、按 Token、按输入素材时长或复合费用的结构化规则。

定价 JSON 没有可靠的在线、离线或已删除状态字段。模型是否对当前账号可用，必须继续以当前账号分组和各分组 `/v1/models` 的交集为准；定价 JSON 只提供展示资料与计费规则。

## 3. 数据优先级

| 数据源 | 唯一职责 | 不负责 |
| --- | --- | --- |
| 登录会话 | 确定用户 ID，并为定价请求提供当前账号 Cookie | 不公开给 Web |
| 当前账号分组与 `/v1/models` | 决定哪些渠道和模型可见、可选择 | 不解释价格 |
| 登录态 `/api/pricing` | 提供介绍、厂商、标签、倍率、计费公式和价格版本 | 不单独证明模型当前可用 |
| `/api/log/self` | 提供已经发生的真实扣费与退款 | 不决定目录价格 |

公开目录只包含“账号目录中可用”且“类型可识别”的模型。仅存在于定价 JSON、但不在账号模型目录中的项目不显示。上游删除模型后继续沿用既定行为：列表中消失，旧节点选择清空，运行前提示重新选择。

## 4. 高内聚、低耦合模块

```text
aihubkit/account
  └── 当前登录账号与私密会话

aihubkit/pricingCatalog
  ├── 拉取与校验定价 JSON
  ├── 当前用户内存缓存
  └── 当前用户最近成功的本地快照

aihubkit/pricingExpression
  ├── 白名单解释 billing_expr
  ├── 识别计费类型
  └── 生成档位与估价结果

aihubkit/catalog
  └── 合并账号可用模型与定价资料，输出统一公开目录

Web aihubkitCatalog
  ├── 登录后自动刷新与十分钟轮询
  └── 为设置、画布和节点提供同一份响应式目录

设置/modelChannelCatalog
  └── 只渲染统一目录，不理解上游 JSON 或计费公式
```

价格同步、价格解析、账号可用性和页面展示不得互相越权。画布模型选择器与生成前报价继续复用统一目录和估价器，不能在设置组件内复制价格判断。

## 5. 自动同步与本地快照

1. 登录成功或恢复登录后，Server 立即并行刷新账号模型目录和定价 JSON，不阻塞登录完成。
2. Web 登录态建立后启动单例同步器，立即读取目录，此后每十分钟拉取一次；重复调用合并为一个在途请求。
3. 定价模块先读取按用户 ID 隔离的最近成功快照。网络返回新 JSON 后校验 `pricing_version` 和字段，再原子替换内存与本地快照。
4. 版本未变化时只更新检查时间，不触发不必要的节点模型失效；版本变化或模型目录变化时刷新公开目录和节点模型缓存。
5. 退出登录或切换账号时停止轮询并清空 Web 与 Server 运行时状态；本地快照始终按用户 ID 隔离，不能跨账号展示。

本地只保存经过规范化的公开模型资料、计费公式和同步时间，不保存 Cookie、Access Token、分组 API Key、完整上游响应、临时上传地址或签名 URL。

## 6. 计费类型与展示契约

计费类型必须从 `billing_expr` 的变量依赖和 `deferred` 结构得出，`description` 只原样展示：

| 类型 | 页面标签 | 示例展示 |
| --- | --- | --- |
| 输出时长影响金额 | 按秒 | `720p · 0.27/秒` |
| 仅输出数量影响金额 | 按条或按张 | `720p · 5.72/条` |
| 使用 `deferred` | 按 Token | `按 Token · 参考 0.13/秒起` |
| 输入音频时长影响金额 | 按输入音频时长 | `0.01 基础费 + 0.35/输入音频秒` |
| 参考素材等额外维度影响金额 | 复合计费 | `生成费 + 参考素材附加费` |

分辨率档位直接显示 `480p`、`720p`、`1080p` 等实际名称，不显示“几档”。固定十五秒、固定三十秒等能力约束不从介绍文字自动写入节点参数；它们继续由模型能力映射决定，介绍只作为详情说明。

公开 Web 数据不包含原始 `billing_expr`，只包含经过 Server 解析的计费标签、提示、价格档位和版本。公式出现未知语法时显示“价格规则待核对”，不能猜成按秒或按条。

## 7. 设置页面

设置侧栏新增独立“模型渠道大全”。当前“文本模型”和“媒体模型”保留第三方与自定义供应商配置，动态 AIHubKit 目录统一移到新板块，避免三个页面重复维护同一职责。

页面为只读结构：

1. 顶部显示当前账号、可用模型数、渠道数、最近自动同步时间和数据状态；正常状态不显示同步按钮，失败时只显示“重新同步”。
2. 使用文本、图片、视频筛选；每类按当前账号渠道分组。
3. 渠道标题展示上游说明、渠道 ID、当前账号倍率、可用模型数和“当前账号可用”。
4. 模型条目展示名称、厂商、上游介绍、标签、计费方式和当前分辨率价格；没有介绍的字段直接省略。
5. 同步部分失败时保留成功内容并标记“本次同步不完整”；不能把请求失败显示成模型下架。

## 8. 错误与安全

- 新响应整体校验失败时不得覆盖最近成功快照。
- 当前账号没有成功快照且定价请求失败时，仍展示可用模型，但价格区域显示“价格暂未同步”。
- 公式局部无法解析时只降级该模型的价格信息，不阻断其他模型或生成。
- 登录失效时停止同步并回到登录页；不得退回公共倍率。
- 前端、画布文件、日志和 Git 中不得出现 Cookie、Token 或分组 API Key。

## 9. 验收标准

1. 重启客户端并自动恢复登录后，无需打开设置或点击按钮即可发起当前账号目录与定价同步。
2. 打开“模型渠道大全”时展示当前账号可用的文本、图片和视频渠道；价格与当前登录账号倍率一致。
3. `sd-2.0-v1` 显示“按条”，并显示 480p、720p、1080p 的条价；不能显示成按秒。
4. `MiniMax-H3` 显示“按秒”；数字人模型能区分输入音频时长计费；Token 模型明确标记为预计。
5. 断网重启时可使用该账号最近成功快照；页面标出上次更新时间，不展示其他账号缓存。
6. 上游删除模型后，下次目录同步不再显示；旧节点模型留空并提示重新选择。
7. 设置板块不含编辑、启停或 API Key 操作；同步失败时允许一次明确的重试。
8. 现有 typecheck、build、真实只读接口检查和 macOS 客户端页面检查通过；不自动发起付费生成。
