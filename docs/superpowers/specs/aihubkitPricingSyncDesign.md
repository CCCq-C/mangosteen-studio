# 山竹漫剧 AIHubKit 动态定价与实际扣费校准设计

- 状态：已确认，待实施
- 确认日期：2026-10-18
- 采用方案：C（定价 JSON 预估 + 当前用户实际日志校准）
- 上游定价入口：`https://model.aihubkit.com/api/pricing`

## 1. 目标与本批边界

本批为已经接入的 AIHubKit 图片、视频模型增加当前账号专属价格同步、生成前预计额度和本地实际扣费历史。模型、分组与价格都由上游接口返回，不硬编码页面上观察到的模型数量或分组名称。

本批不建设跨用户汇总服务器，不统计其他用户，不接入支付，也不把“预计价格”当作最终账单。文本模型仍只同步目录；文本 Token 价格展示留到语言生成链路接入时处理。

## 2. 已验证的上游事实

2026-10-18 使用当前登录会话完成只读验证：

1. `GET /api/pricing` 返回 94 个模型、21 个当前账号分组、顶层 `pricing_version`、模型级 `pricing_version`、`enable_groups`、`model_sales_ratios`、`billing_mode` 与 `billing_expr`。
2. 只发送 Bearer Token 会得到公共倍率；发送登录 Cookie 后才得到当前账号倍率，例如 `gemini_image = 1.5`、`video = 1.1`、`video_官key = 1.1`，并出现“森雪赚专用”。因此定价同步必须使用 Server Keychain 中的会话 Cookie，不能复用仅 Bearer 的公共结果。
3. `sd-2.0-720p` 的公式为基础价 `0.73 × seconds × units`，当前分组倍率为 `1.1`，页面展示 `0.803/秒`。
4. `MiniMax-H3` 的 768p 基础价为 `0.198/秒`，4 秒、`video 1.1×` 的实际日志费用为 `435600 / 500000 = 0.8712`，与公式一致。
5. `gemini-3-pro-image-preview` 的固定基础价为 `0.15/次`，`gemini_image 1.5×` 的实际日志费用为 `0.225`，与公式一致。

## 3. 数据源与优先级

三个来源职责互不重叠：

| 来源 | 职责 | 失败时行为 |
| --- | --- | --- |
| 当前分组与 `/v1/models` | 决定当前账号能选择哪些分组和模型 | 保留最近一次成功目录，不伪造模型 |
| 登录态 `/api/pricing` | 提供当前价格公式、模型分组销售倍率与价格版本 | 保留最近一次成功价格并标记为旧数据；没有缓存时只隐藏价格 |
| `/api/log/self` | 提供当前用户已经发生的真实扣费 | 不影响生成；继续使用目录价格预估 |

模型是否可用只由模型目录决定。定价接口中存在但当前分组模型目录没有的模型，不进入设置或画布。模型被删除后继续沿用现有规则：下拉中直接消失，旧节点选择清空，运行前提示重新选择。

## 4. 模块边界

```text
AIHubKit account（Keychain 会话唯一所有者）
  ├── catalog（分组、模型、私有分组 Key）
  └── pricing
      ├── pricingCatalog（登录态价格 JSON、缓存、版本）
      ├── pricingExpression（只读安全解析与估价）
      └── pricingHistory（当前用户实际日志、本地持久化）

catalog + pricing 的公开摘要
  ├── 设置页：分组、模型、价格摘要、最近实际
  └── 媒体模型：价格能力与选择器摘要

现有 /api/ai/media/price
  └── AIHubKit estimator：按当前节点参数返回预计额度与依据
```

账户模块只新增 Server 内部读取会话 Cookie 的能力，不向 Web 返回 Cookie、Token 或分组 Key。价格模块不创建生成任务；媒体生成模块只调用估价和生成后刷新入口，不理解价格 JSON 结构。

## 5. 定价 JSON 规范化

每个当前账号的“分组 + 模型”关系规范化为：

```ts
interface AihubkitPriceSummary {
  label: string;
  tips: string;
  kind: "fixed" | "perSecond" | "tokenEstimate" | "dynamic";
  pricingVersion: string;
}
```

公开目录只返回上述可展示摘要，不返回原始 `billing_expr`。Server 内存保留经过校验的原始规则供估价；本地历史只保存规范化维度和实际额度，不保存 Cookie、Token、API Key、完整响应或签名 URL。

## 6. 安全公式解释器

`billing_expr` 是上游数据，禁止通过 `eval`、`Function` 或动态模块执行。使用仓库现有 `@babel/parser` 解析表达式，再由白名单解释器处理媒体定价需要的节点：

- 字面量、标识符、括号；
- `+ - * /`、比较运算和 `&& ||`；
- 条件表达式；
- 仅允许 `tier`、`usd`、`deferred`、`max` 四个函数；
- 仅允许媒体维度 `resolution_tier`、`seconds`、`units`、参考素材数量与素材时长。

任何未知语法、未知变量、非有限数、负数或无法匹配的档位都返回“暂无预估”，不能猜价格。解释器只计算数值并返回命中的档位，不产生任何副作用。

## 7. 估价规则

| 计费类型 | 生成前展示 | 生成后处理 |
| --- | --- | --- |
| 图片固定价 | `model_price × model_sales_ratios[group] × units` | 日志刷新后记录最近实际 |
| 视频按秒/按次 | 选择档位后计算公式，再乘当前模型分组倍率 | 日志刷新用于核对并显示最近实际 |
| 视频 Token 延迟结算 | 有完全相同维度历史时优先使用最近实际；否则使用 `deferred` 内的上游参考公式 | 新日志覆盖同维度的旧样本 |
| 未知或不完整规则 | 不显示数字，只提示以实际扣费为准 | 若日志含完整维度则可形成历史参考 |

“完全相同维度”至少包含用户 ID、分组、模型、分辨率、输出时长、输出数量、图片/视频/音频引用数量与可取得的引用时长。不同清晰度、不同参考模式不得混用历史价格。

金额统一显示为“额度”，例如“预计 0.803 额度”；本批不显示人民币或美元符号，因为上游页面符号与模型说明单位不一致。

## 8. 实际价格历史

价格历史只针对当前登录用户：

1. 定价同步后读取最近 100 条 `/api/log/self`；生成成功后后台再刷新一次。
2. 只保留当前价格目录可识别的图片、视频与数字人模型。
3. 使用 `quota / 500000` 得到实际额度；无效、负数或缺少模型/分组的记录丢弃。
4. 按“用户 + 分组 + 模型 + 计费维度”只保留最新样本，每个用户最多 500 个维度样本。
5. 通过现有 `conf` 写入本地数据目录；切换账号时按用户 ID 隔离，不上传到山竹服务器或第三方。

当前没有中心服务器，因此不同用户、不同电脑之间不共享历史。未来增加服务器时只替换 history 存储适配器，不改变目录、估价和界面契约。

## 9. 同步与缓存

- 登录、恢复会话：目录同步时同步价格，并后台更新实际日志。
- 应用运行：沿用目录的 10 分钟刷新周期。
- 手动“同步模型”：同时强制刷新价格。
- 节点报价：复用现有 30 秒参数报价缓存。
- `pricing_version` 变化：替换当前价格规则并清理节点报价缓存。
- 定价或日志刷新失败：模型目录和生成链路继续可用，设置页显示最近成功价格或不显示价格。

## 10. 界面

1. 设置 → 媒体模型：每个模型显示当前分组价格摘要；提示中展示计价方式、档位数量、同步来源和最近实际样本。
2. 图片/视频节点模型下拉：模型名称后显示简短价格摘要，不再显示旧供应商价格。
3. 节点生成按钮旁：复用现有 `mediaPrice` 组件，按当前时长、清晰度和参考素材实时显示预计额度。
4. Token 模型必须明确标“预计”或“参考最近实际”；确定性公式也保留“最终以实际扣费为准”的提示。

## 11. 能力参数边界

模型与分组来自实时 API；价格档位来自实时定价 JSON。视频可选时长、分辨率与比例继续由已经实现的生视频接口文档映射提供，因为当前模型接口没有返回完整能力 Schema。若价格 JSON 没有所选清晰度档位，则不显示预估，不自动改写用户参数。

## 12. 验收

1. 当前账号同步结果包含账号专属倍率，不使用公共 1× 价格。
2. 设置页图片和视频模型显示对应分组价格，不出现“优云智算”或“APIMart”模型。
3. 图片节点 `gemini-3-pro-image-preview / gemini_image` 显示约 `0.225 额度`。
4. 视频节点 `sd-2.0-720p / video_官key` 在选择 5 秒时显示约 `4.015 额度`。
5. Token 视频模型在没有历史时使用上游参考价并标记预计；有完全相同维度历史时显示最近实际参考。
6. 定价接口断网或返回未知公式时，价格降级但图片/视频模型目录和生成不被阻断。
7. 全仓 typecheck、build 与 macOS 客户端只读界面检查通过；不自动发起付费生成。
